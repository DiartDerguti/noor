# Noor

Kurani dhe hadithi ne shqip, nga burime zyrtare.

The Quran and authentic hadith in Albanian.

Live: [noor-al.netlify.app](https://noor-al.netlify.app/)

# Permbajtja

- Kurani- 114 suret me tekstin arab dhe tre perkthime shqip: Hasan Efendi Nahi, Sherif Ahmeti, Feti Mehdiu. Mund t'i krahasosh te tria.
- Hadithe - vetem nga Buhariu dhe Muslimi, me shpjegim per secilin.
- Meso - kuiz i shkurter per suret dhe hadithet.

# Burimet

- Kurani: [Quran.com](https://quran.com) (teksti arab), [Tanzil](https://tanzil.net) (perkthimet shqip)
- Hadithet: [HadeethEnc](https://hadeethenc.com)

# English

Noor is a simple site for reading the Quran and authentic hadith in Albanian, using official sources only.

# Features

- Quran - all 114 surahs with the Arabic text and three Albanian translations: Hasan Efendi Nahi, Sherif Ahmeti, Feti Mehdiu. You can compare all three side by side.
- Hadith - only from Bukhari and Muslim, each with an explanation.
- Learn - a short quiz about the surahs and hadiths.

# Sources

- Quran: [Quran.com](https://quran.com) (Arabic text), [Tanzil](https://tanzil.net) (Albanian translations)
- Hadith: [HadeethEnc](https://hadeethenc.com)

# Run locally

```bash
git clone https://github.com/DiartDerguti/noor.git
cd noor
npm install
npm run dev
```

Built with Next.js 16, React 19 and Tailwind CSS 4. Hosted on Netlify.
